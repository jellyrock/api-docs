# JellyRock API Docs (retired)

This repo generated a JSDoc reference for the
[JellyRock](https://github.com/jellyrock/jellyrock) Roku app's BrightScript
and published it at api.jellyrock.app. It was retired on 2026-10-23 and is
archived. The site is offline and there is no replacement.

For working on JellyRock, see the developer docs at
**[dev.jellyrock.app](https://dev.jellyrock.app)** and the code itself in
[jellyrock/jellyrock](https://github.com/jellyrock/jellyrock).

The history stays here, read-only, for reference.
